# Coffee Shop Sales Analysis – Power BI Dashboard

## Overview

This project presents an interactive **Coffee Shop Sales Analysis dashboard** created using **Microsoft Power BI**.

The dashboard provides a visual overview of coffee shop sales performance, transaction activity, coffee type revenue, payment methods, daily sales trends, and sales by time of day.

## Objectives

- Analyze overall coffee shop sales performance
- Understand revenue generated by different coffee types
- Analyze daily sales and transaction trends
- Compare payment methods used by customers
- Identify sales patterns across different times of the day
- Present business information through clear and interactive visualizations

## Dashboard Highlights

The dashboard includes:

- **Total Sales**
- **Average Transaction Value**
- **Number of Transactions**
- **Revenue by Coffee Type**
- **Sales Trend by Day**
- **Sales by Payment Type**
- **Sales by Time of Day**

## Key Metrics

- **Total Sales:** $115.4K
- **Average Transaction Value:** $31.7
- **Number of Transactions:** 3,636

## Visualizations

### Revenue by Coffee Type
Shows the revenue generated by different coffee types such as Latte, Americano, Cappuccino, Hot Chocolate, Cocoa, Cortado, and Espresso.

### Sales Trend by Day
Displays sales and transaction patterns across the days of the week.

### Sales by Payment Type
Shows the distribution of sales between card and cash payments.

### Sales by Time of Day
Compares sales across different time periods such as Morning, Afternoon, and Night.

## Tools Used

- Microsoft Power BI
- Power Query
- Data Visualization
- Data Analysis

## Project Outcome

This dashboard demonstrates how Power BI can be used to transform sales data into meaningful visualizations and present business information through an interactive dashboard.
